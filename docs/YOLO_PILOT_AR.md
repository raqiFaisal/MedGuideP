# كاشف العلبة التجريبي في MedGuide

يُفعّل كاشف YOLO التجريبي عند ضبط `MEDGUIDE_ENABLE_PILOT_YOLO=1` قبل تجهيز أصول التطبيق. يضع إطارًا حول موضع محتمل للعلبة في الصورة بعد الضغط على «حلّل الصورة». يظهر الإطار عند وجود صندوق واحد فوق عتبة الاختبار 0.65 بعد إزالة الصناديق المتداخلة. تظل قراءة الباركود والنص ومطابقة سجل الدواء مستقلة عن هذا الإطار. عند غياب النموذج أو تعذّر تشغيله يواصل التطبيق تحليل الصورة.

## إعادة اختبار حزمة أندرويد

من جذر حزمة المصدر التي تتضمن القاعدة وملف ONNX:

```bash
cd mobile
npm ci
export MEDGUIDE_ENABLE_PILOT_YOLO=1
npm run assets:setup
npm run typecheck
npm run lint
npm test -- --runInBand
npx expo export --platform android
```

يتطلب تثبيت التطبيق على الهاتف بناء أندرويد أصليًا. يُرفق تقرير التصدير في `models/mobile/yolo_pilot_export_report.json` ويتحقق برنامج تجهيز الأصول من بصمة ONNX قبل نسخه.

## التحقق المنجز

حُوّل وزن `best.pt` إلى ONNX opset 17 بإدخال `1×3×640×640` وإخراج `1×5×8400` لفئة العلبة. فُحص نموذج ONNX وقورنت مخرجاته مع PyTorch على مدخلين اصطناعيين باستخدام ONNX Runtime 1.24.3. أكبر فرق لإحداثيات الصناديق بلغ 0.00062 بكسل وأكبر فرق للثقة بلغ 0.0000015. هذان الاختباران يفحصان صحة التحويل. قياس الدقة يتطلب صورًا مستقلة بمعرّفات منتجات موثقة.

عادت البيئة على نسخة المستودع الأصلية. أُعيدت شاشة التصوير من النسخة الاحتياطية الموجودة فيه، وأُعيد تجهيز القاعدة من المصدر المصري وملفَي السعودية المرفقين. أُضيف مسار YOLO أعلاه على هذه النسخة. بقيت التعديلات المحلية السابقة الأخرى بحاجة إلى أرشيف المصدر السابق لاستعادتها.
