# استعادة وظائف التعرّف وتجهيز حزمة الاختبار

أُعيد بناء تبديل العربية والإنجليزية والسجل المحلي وتصحيح المنظور فوق نسخة YOLO المتاحة في المستودع. الالتزامان المحليان القديمان وأرشيفهما غير موجودين في الجلسة. تُحفظ اللغة والسجلات الاختيارية في قاعدة مستقلة عن كتالوج الأدوية. تُربط السجلات برمز المصدر ومعرّف صفه. يمكن حذف السجل من الإعدادات.

## حزمة OCR والكاشف

أصبح OCR يعمل محليًا في مسار الصورة عبر كاشف النص PP-OCRv4 الموزع مع RapidOCR ونموذجَي EasyOCR للقراءة بالعربية والإنجليزية. بعد تجهيز الصورة يحاول OpenCV تصحيح منظور العلبة عند وجود حواف رباعية واضحة، ثم يستخدم التطبيق الصورة الأصلية إذا تعذّر التصحيح أو القراءة. يظل الباركود مرتبطًا بالصورة الأصلية أو القصاصة التي يحددها كاشف معتمد. يمر اسم الدواء والتركيز المقروءان إلى المطابقة لاقتراح سجلات للمراجعة.

يسحب مسار الإطار الحي عينات إضاءة منخفضة الدقة من CameraX محليًا. يعمل كاشف YOLO التجريبي على هذه العينات ويعرض إطارًا عند وجود كشف واحد. يمكن التقاط الصورة يدويًا في كل الحالات. لم يُختبر هذا التكامل الأصلي وتطابق إطار الشاشة على هاتف بعد.

تمت مقارنة مخرجات ONNX مع PyTorch على مقاسات نص قصيرة وطويلة. عمل كاشف النص ونموذجا القراءة على صورة نص اختبار اصطناعي وقرآ `PANADOL 500 mg` و«بنادول ٥٠٠ ملغ». هذا فحص تشغيل ولا يكفي لاعتماد الدقة على صور الأدوية الحقيقية. نموذج العربية الكامل حجمه قرابة 215 MB ويحتاج قياس الذاكرة وزمن الاستجابة على Galaxy S9+.

## التجهيز من فرع main

يتضمن فرع `main` المصدر والقاعدة ونماذج التشغيل. نموذج العربية موزّع على أجزاء في `models/mobile/package_ocr_arabic.onnx.parts/` بسبب حد حجم الملف على GitHub. يجمع `npm run assets:setup` هذه الأجزاء ويتحقق من بصمة SHA-256 للنموذج الكامل قبل استخدامه. بعد تنزيل فرع `main` أو استنساخه، نفّذ أوامر أندرويد أدناه من جذر المشروع.

## إعادة التجهيز من الأرشيفين

فك أرشيف المصدر داخل مجلد عملك، ثم فك أرشيف نماذج OCR في **المجلد نفسه**. يضيف أرشيف OCR ملفات `models/mobile/package_ocr_*.onnx` إلى مشروع MedGuide. أرشيف المصدر يتضمن قاعدة مصر والسعودية، كاشف YOLO، تقارير التصدير وقواميس OCR.

```bash
cd MedGuide/mobile
npm ci
export MEDGUIDE_ENABLE_PILOT_YOLO=1
npm run assets:setup
npm run typecheck
npm run lint
npm test -- --runInBand
npx expo prebuild --platform android
npx expo export --platform android
```

يتحقق برنامج تجهيز الأصول من البصمات. يتطلب تشغيل الإطار الحي وتصحيح المنظور نسخة أندرويد أصلية، وتبقى تجربة الهاتف شرطًا قبل الاعتماد. يُعاد توليد OCR بواسطة `engine/eval/export_package_ocr.py` ويمكن إعداد بيئته بـ EasyOCR 1.7.2 وRapidOCR 1.4.4 وONNX Runtime 1.24.3. يقبل البرنامج وزنَي EasyOCR المنشورين ضمن إصداري Arabic G1 وEnglish G2 بعد فحص SHA-256.

## الفهرس ومجموعة الاختبار

يقبل بناء الفهرس `--embedding-onnx` لاستعمال نسخة كاشف البصمة نفسها في Python وأندرويد. يدقق رقم المنتج ورمز مصدره ومعرف صفه ويتحقق التطبيق من بصمة الكتالوج ونموذج التضمين قبل استخدام الفهرس. جرى اختبار استيراد فهرس اصطناعي ورفض صف غير مطابق ورفض إعادة استخدام صورة مرجعية في التقييم. تظل أوزان DINOv2 وصور العلب المرجعية المرتبطة بمنتجات حقيقية وصور الاختبار المستقلة متطلبات لقياس الدقة ونشر الفهرس.

مصادر النماذج [EasyOCR](https://github.com/JaidedAI/EasyOCR) و[RapidOCR](https://github.com/RapidAI/RapidOCR) و[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR). تُستخدم بيانات المشروع بحسب تراخيصها الموثقة في `docs/LICENSES.md`.
