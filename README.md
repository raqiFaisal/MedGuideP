# MedGuide

تطبيق أندرويد للبحث عن الأدوية في قاعدة مصر والسعودية وقراءة نص العبوة محليًا.

يتضمن فرع `main` كود المشروع والقاعدة ونماذج التشغيل. يجمّع إعداد الأصول نموذج OCR العربي من أجزائه ويتحقق من بصمته تلقائيًا.
