# تنزيل MedGuide

نزّل هذا الفرع كملف ZIP من GitHub وفك الضغط أولًا. على ويندوز شغّل `Assemble-MedGuide.cmd`. على Linux أو macOS شغّل `bash assemble-medguide.sh`. ستجمع الأداة الأجزاء وتتحقق من SHA-256 وتنتج `MedGuide-8fb7441.zip` في المجلد نفسه.

يتضمن الملف الناتج المصدر عند الالتزام `8fb7441` ونماذج OCR وYOLO وقاعدة SQLite لمصر والسعودية. بعد فك الملف الناتج، توجد تعليمات المشروع في `MedGuide/docs/RECOGNITION_RESTORE_AR.md`.
